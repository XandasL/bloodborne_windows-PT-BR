# Changes 2026-10-02 (Local Development Audit)

Overview of optimizations, verification procedures, and performance measurements on Radeon RX 7800 XT / RADV, with CPU scaling verified under `taskset` (4 cores / 8 threads).

## Performance and Frame Pacing

### Handheld & Mid-Tier GPU Path (Steam Deck / GTX 1060)

For non-1080p output (720p on Steam Deck, 1440p, 2160p), the full rendering pipeline executes at the preset resolution (startup patch). Dynamic scaling retained post-processing in 1080p with ping-pong scene blits, which created unacceptable bottlenecks on lower-spec hardware.

- Dynamic resolution switching is configurable via launcher / in-game menu (`bbport.ini` `live_resolution=auto|0|1`). **Auto** enables live switching on discrete GPUs with 8+ GB VRAM (Turing or newer / RDNA); handhelds and legacy cards default to the direct path. Override via `BB_LIVE_RES=0/1`.
- Changing presets, display output resolution, or switching to TAA when dynamic resolution is off is applied via "Apply & Restart Game".
- Depth/stencil downscaling on GPUs lacking `VK_EXT_shader_stencil_export` (Pascal) stays full-resolution without multi-pass emulation overhead.

### Frame Pacing Under Heavy GPU Load

1. **Dedicated Presentation Thread:** Frame presentation (`vkAcquireNextImage`, `vkQueuePresent`) previously ran directly on the game's vblank thread. Under heavy GPU load, presentation blocking caused erratic vblank pacing. Presentation is now offloaded to a dedicated `bb:Present` thread (`BB_PRESENT_THREAD=0` restores inline presentation).
2. **GPU Pipelining Depth Cap:** Capped command submission ahead of presentation to `BB_FRAMES_AHEAD` frames (default 1; 0 is unconstrained).

4K Native without upscaler, ~78 FPS, camera pan test (5-second windows):

| Configuration | FPS | Frame Time Variance | p99 | Frames > 1.5x Median |
|---|---|---|---|---|
| Baseline | 79.5 | 9.9 ms | 25.8 ms | ~125 |
| Dedicated Present Thread | 79.4 | 5.9 ms | 25.0 ms | ~80 |
| + Frame Ahead = 1 | 77.4 | **0.9 ms** | **14.6 ms** | **0** |

Added `Frame pacing:` metrics output to `BB_FRAME_STATS=1`.

### Pipeline Cache Invalidation & Rebuilding

Previously, shader cache profile mismatches permanently disabled caching for the entire session and left the stale profile intact, forcing cold compilation on every boot.

Incompatible caches now trigger an automatic rebuild with clean logging (`Pipeline cache isn't compatible with current system: rebuilding it`). Successive runs over identical routes dropped cold compilations from 241 down to 28.

### CPU Workload Optimization

Under CPU bottlenecks (4 cores / 8 threads @ 720p FSR 3 Performance): ~166 FPS sustained.
- Vulkan command recording worker adjusts active spin-wait duration dynamically based on process CPU affinity.
- Secondary stage spin-wait duration scales with available core count (`BB_PIPE_SPIN_US`).
- Relaxed Readback mode (protecting FaceGen vertices) adds negligible overhead (166.4 vs 166.3 FPS).

## Stability

### Resolved Race Condition (`Guest fault … 0x263b8e7`)

`sceGnmSubmitDone` returned early if the command thread had finished parsing buffers (`num_submits == 0`), even while secondary recording stages and deferred fence markers were pending completion. Added `work_retired` latch: GPU is only marked idle when pipeline stages and pending fence markers have retired completely.

## Visual Fidelity & Shaders

- **Sharpness extended to 2.0**: Values <= 1.0 drive upscaler RCAS; values > 1.0 apply an additional RCAS pass across final output.
- **Ctrl+Click Slider Numerical Input**: Enabled ImGui text input handling via SDL text events.
- **NVIDIA Pascal (GTX 10xx) Geometry Flickering**: For GPUs lacking `VK_KHR_fragment_shader_barycentric`, the shader recompiler scales interpolated attributes by $1 + 2^{-16}$ prior to integer truncation, restoring proper 1.0 rounding.
- **Shader Recompiler Fixes from Upstream shadPS4**: Added `V_CVT_PK_U8_F32`, `V_BFM_B32`, `V_ALIGNBIT/ALIGNBYTE_B32`, SCC carry in `S_ADDC/S_SUBB_U32`, 32-bit literals in 64-bit ops, compute floating point control modes, and P10/P20 selectors in `V_INTERP_MOV_F32`.

## Mods, Patches, & Launcher

- File mod loader supports arbitrary directory nesting, case-insensitive overrides, and unbundled `dvdroot_ps4` replacements (`Mods: N game files replaced, M added`).
- Third-party XML patch support in `patches/` with selection saved to `patches.json`.
- 60/90 FPS patches relocating internal jump tables are automatically re-based to the image address.
- Full English localization with system locale fallback.

- Memory growth levels off after initial cache warmup (pipeline & texture descriptor caches).
- Long-duration runs (40 minutes) exhibit stable memory consumption (RSS ~2.64 GB, VRAM ~4.29 GB).
