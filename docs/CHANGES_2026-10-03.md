# Changes 2026-10-03 (Local Development Audit)

Measurements taken on Radeon RX 7800 XT / RADV constrained via `taskset` to 4 cores / 8 threads, Steam Deck profile (1280x720 output, FSR 3 Performance, 640x360 scene), unconstrained framerate.

## Dynamic Resolution Switching — Disabled by Default

Unspecified `live_resolution` (fresh install, launcher, menu) defaults to "disabled": for non-1080p display targets, the engine applies the startup resolution patch (as in release 0.1). `auto` and `1` can be explicitly selected.

## AppImage & Neural Models

Neural models extracted from vendor DLLs are not bundled in public redistribution packages. `packaging/default.nix` packages `fsr4_411` assets only when `BB_PACKAGE_FSR411=1` is specified; otherwise assets are resolved from the user data directory.

## Handheld Architecture: Startup & Texture GC

- **NixOS AppImage Execution**: Replaced external `sed` dependency in `run.sh` with bash builtins.
- **Integrated GPU Texture Garbage Collection** (`TextureCache::GarbageCollectImages`): Replaced static 8 GB overhead reservation with `VK_EXT_memory_budget` proportional thresholds (collection at 70%, pressure at 85%, critical eviction at 95%). Override via `BB_GC_BUDGET_MB=N`.
- **Synchronous Evicted Texture Writeback**: Dirty evicted textures are now written back to game memory synchronously while page write permissions remain guarded, preventing out-of-order memory corruption upon location unloads.

## Optimized Dynamic Resolution Scaling

- Half-resolution render targets (960x540, including bloom mip chains) now scale proportionally with the scene factor (`ProxySize`).
- Individual mip levels in half-res chains maintain dedicated downscaled copies; single-level lookups sample the proxy while whole-chain sampling accesses the resolved image.
- GPU frame time on PC (4c/8t) reduced from 3.41 ms to 3.23 ms.

## TAA: Distant Silhouette Shimmer

Thin geometry (window bars, railings, debris edges) previously flickered due to depth validation rejection during subpixel jitter phases. For motion under 1 pixel, history is preserved and clamped to neighborhood bounds.

Metric: 30 consecutive frames with static camera (`BB_PRESENT_DUMP_COUNT=30`), mean second-order temporal luminance difference (frame-to-frame shimmer, x1e-3):

| Mode | Mean | p99.9 |
|---|---|---|
| Previous (2 runs) | 0.367 / 0.381 | 23.2 / 22.0 |
| Current (2 runs) | 0.266 / 0.293 | 12.2 / 13.1 |
| Unjittered Baseline | 0.428 | 16.8 |

## Upscaler Audit Alignments

- Native AA beyond 1080p verified.
- Sky background rotation and relative depth validation for object motion vectors verified.
- **Negative Mip Bias**: G-buffer passes (5+ targets) under downscaled scenes apply sampler LOD bias equal to $\log_2(\text{render} / \text{output})$ (-1.0 on Steam Deck). Shadows, post-processing, and UI remain at neutral bias. Log confirms: `Upscaler: scene texture LOD bias -1.00`. Toggled via bit 57.

## CPU Profiling (4c/8t)

Under patched mode (209 FPS sustained): threads consumed ~545% of 800% capacity (`bb:DrawRec` 72+14%, command thread 56+20%, `bb:VkRecorder` 72+1%, main thread 46+10%, 4 prep workers ~20% each). Primary remaining scaling barrier is single-threaded Vulkan command submission.
